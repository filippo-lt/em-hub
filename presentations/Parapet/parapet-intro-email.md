Hi everyone,

I'm writing to introduce **Parapet**, a shared quota and token management system now available for intgration in any app in the portfolio.

**What it does**

Parapet provides four capabilities out of the box:

- **Device authentication**: verifies real users on real devices
- **Quota management**: configurable usage limits with automatic resets (daily, weekly, monthly, billing cycle)
- **Token / credit system**: persistent consumable credits, independent of subscriptions
- **Subscription sync**: RevenueCat integration handled automatically

Once integrated, everything is managed through a **Control Center**: a web dashboard where product and support teams can configure limits, view user state, and debug issues directly. No engineering needed. Changes take effect immediately.

**Integration**

Parapet handles all the heavy lifting: RevenueCat webhooks, subscription state, quota resets, device attestation, billing cycles; so developers just integrate an API instead of building it all from scratch. What used to take weeks now takes less than 5 days.

**Where we are**

Parapet is live in **Photo Up** and **Face AI**, with more integrations planned. It is available for integration for iOS, Android, and Flutter. Web will follow shortly.
