What Parapet handles

Four capabilities, one system — so your apps don't have to build any of them

Device authentication

  • Verifies real users on real devices
  • Firebase App Check + Apple App Attest
  • Platform-level fraud prevention

Quota management

  • Per-user limits per feature
  • Daily, weekly, monthly, or billing resets
  • No code changes needed

Token system

  • Credits bought via in-app purchase
  • Available to free and paid users
  • Pricing controlled from the backend

Subscription sync

  • Keeps quota and token state in sync
  • Handles purchases, renewals, and refunds
  • No manual handling
Platform support iOS Android Flutter Backend Web — coming soon

Multi-tenant — one system, all apps
