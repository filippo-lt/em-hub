Key Design Decisions
👤
User Identity
v1.0 Scoped
RevenueCat runs in anonymous mode for v1.0. Architecture keeps the door open for identified users when authentication lands. Identity sync across all three SDKs handled by a single setUser(id:) call.
⚙️
CI/CD Pipeline
Discuss with Victor
Keep it simple for v1: GitHub Actions runs tests on PR. Full release automation (semantic versioning, SPM tag publishing) is a v1.1+ concern — don't let it block the pilot.
Open Questions for MarTech
For discussion with David Sanchez 4
01
Event naming conventions — Does MarTech have an existing taxonomy or naming scheme for Amplitude events? This will directly shape the v1.1 MarTechEvent catalogue. Better to align before building.
02
SDK key ownership long-term — Currently no one owns the API keys formally. Should MarTech own and rotate them? Should mobile hold them? Needs a clear owner before we scale beyond Face AI.
03
Rollout sequencing beyond Face AI — After the Face AI pilot, which app is next? Does MarTech have a priority order, or does mobile decide? Answering this shapes the v1.1 migration scope.
04
Other features — Are there additional capabilities MarTech wants to consolidate into the package beyond the current scope? Identifying these early prevents costly rework after v1.0 ships.
