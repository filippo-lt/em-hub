## 4. Goya/Mirage: decision needed

Delisting removes the apps from the store. **The backend stays live.** Existing installs keep working, and so does an attacker.

| Issue | Fixed by delisting? | What really closes it |
|---|---|---|
| API keys exposed in Firebase (mitigated with Firestore rules) | ❌ | **Rotate/revoke the keys.** Rules hide them, but leaked keys can still be valid. |
| Attackers can impersonate the app and use our backend (~272k replayable tokens, per the audit) | ❌ | Shut down the backend or the GCP project, or wipe the `tokens` collections. |
| User data still stored | ❌ | Delete it. Keeping it with no purpose is also a GDPR problem. |
